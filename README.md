Personal Portfolio Website

This is my personal portfolio website, which is the mandatory part of my web development assignment. 
I built it to showcase my profile, the coding languages I know, my education, and my projects.

What It Does

It is a single-page website where you can scroll through different sections about me. 
I used basic HTML and CSS to style it, and added some JavaScript to make it a little interactive, like adding a dark mode button and a 
contact form that checks if you entered an email correctly.

Main Features

Smooth Scrolling: The top navigation bar has links to About, Skills, Projects, and other sections. 
When you click them, the page scrolls down to that specific part of the website.

Dark and Light Mode: There is a button in the navigation bar that switches the whole website between a light theme and a dark theme. 
It works by using JavaScript to change the CSS class on the body tag.

Resume Popup: Clicking the Resume button opens a popup box on top of the page. 
It displays my actual resume PDF. You can click close to hide it.

Form Validation: The contact section has a form. If you try to submit it while it is empty or without an "@" symbol in the email box, 
JavaScript stops it and shows a red error message.

My Info: It includes all my real details, like my Leetcode rating, my GitHub link, and my education history from nursery to college.

Technologies Used

HTML: To build all the sections, the navigation bar, and the contact form.

CSS: To add colors, style the buttons, and create the dark mode look. I used basic inline-block layouts to place things side by side.

JavaScript: To toggle the light/dark theme, show and hide the resume popup, and check the form inputs before submitting.

How to Run

You don't need to install anything to view this website.

Make sure Portfolio.html, PortfolioCSS.css, PortfolioJS.js, and the Shaurya Singh - Resume.pdf file are all saved inside the exact same folder.

Double-click Portfolio.html to open it in Chrome, Edge, or any normal web browser.
